# Exports

This folder holds build outputs (exported binaries, zips, distributables). It is safe to delete and regenerate.

## What goes here
- Godot export output (Windows, macOS, Linux builds, web builds, release zips).
- Release artifacts you want to share outside the repo (optional).

## What does NOT go here
- Source art: use `/art_source/`.
- Game source: use `/game/`.
- Design docs: use `/docs/`.

## Note
If we ever automate builds, this is the target output folder.
