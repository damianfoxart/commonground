# Expanded Scope

This folder contains deeper design constraints and long-form notes. These are not tasks. They are guardrails and reference material.

## What belongs here
- Canon rules that must stay consistent (lore, world rules).
- Design pillars and vision that drive decisions.
- “Safety rails” that prevent scope creep or tonal drift.
- Known risks and failure modes to avoid.

## What does NOT belong here
- To-do lists or sprint tasks.
- Temporary brainstorm notes.
- Implementation details for specific code files.

## Naming and structure rules
- Use lowercase with hyphens for folders. No spaces.
- Keep each topic as one file. If a topic grows, split into clearly named files and update [../README.md](../README.md).
