# Vertical Slice (3–5 minutes)

## Goal
Playable micro-scenario that proves the core loop:
move -> interact -> choose -> village state updates -> outcome shown.

## Must Have
1. Player can move around a small map area.
2. 2 NPCs you can talk to.
3. One simple choice (2–3 options) during a conversation.
4. After choosing, update 3 stats:
   - food
   - morale
   - stability
5. Show the result on screen immediately (UI panel or text).

## Nice To Have
- Simple placeholder art ok.
- Keyboard movement ok (WASD/arrows).
- Dialogue can be basic.

## Definition of Done
- I can launch the game and complete the scenario in under 5 minutes.
- I can clearly see the stats change after the choice.
