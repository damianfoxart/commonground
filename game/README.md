# Game

This folder is the Godot project root (game source and assets live here).

## What goes here
- Godot project files and folders (scenes, scripts, assets, project.godot).
- Anything required to run/build the game in Godot.

## What does NOT go here
- Design docs: use `/docs/` (start at `/docs/README.md`).
- Art source files (working PSD/Krita/etc): use `/art_source/`.
- Exports/build outputs: use `/exports/`.
